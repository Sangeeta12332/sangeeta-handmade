# Sangita Handmade 🌸

An elegant, modern e-commerce web application for **Sangita Handmade** — featuring handcrafted crochet flower bouquets, custom handmade crafts, and personalized gifts.

---

## ✨ Features

- 🛍️ **Product Catalog & Details**: Browse crochet bouquets, car charms, keychains, and accessories with high-resolution imagery and product specifications.
- 🌐 **Bilingual Support**: Instant toggle between **English** and **Hindi (हिंदी)** for global and local accessibility.
- 🛒 **Interactive Shopping Cart & Checkout**: Seamless cart management with order summaries and custom notes.
- 💌 **Custom Order Inquiry**: Request bespoke crochet creations and colors with an interactive customization form.
- 📱 **WhatsApp Direct Ordering**: Instant customer support and order coordination via WhatsApp.
- 🔒 **Admin Portal**: Secure administration dashboard for managing inventory, viewing orders, and handling inquiries.
- ⚡ **Built on Modern Tech**: Next.js 14 App Router, TypeScript, and MongoDB.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: Vanilla CSS Modules (Design Token Architecture)
- **Database**: [MongoDB](https://www.mongodb.com/) with [Mongoose](https://mongoosejs.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Authentication**: JWT & `bcryptjs` for secure admin authentication

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Sangeeta12332/sangeeta-handmade.git
cd sangeeta-handmade
```

### 2. Install dependencies
```bash
npm install
```

### 3. Set up environment variables
Copy the `.env.example` file to `.env`:
```bash
cp .env.example .env
```
Update the required environment variables (MongoDB URI, JWT secrets, etc.).

### 4. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Build & Production

To build the project for production:
```bash
npm run build
```

To run the production build:
```bash
npm run start
```
